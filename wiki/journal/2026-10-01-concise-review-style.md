# Apply concise architect review style

For [issue #49](https://github.com/JFusco/agent-review-workflows/issues/49),
the shared helper prompt now asks review roles to behave as pragmatic,
minimalist senior architects: name supported edit locations, stay within the
immediate requirement, prefer simple corrections, suggest only material tests,
and omit filler. Newly refined plans use a clean actionable checklist.

The plan and implementation skill entrypoints link to the shared CLI guidance.
No review stage, response schema, model profile, finding identity, or write
boundary changed. Deterministic prompt assertions verify the instruction;
provider quality remains unmeasured.
