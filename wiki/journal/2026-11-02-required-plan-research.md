# Required research before plan review

Implemented the supplied [plan](../plans/2026-11-02-add-required-research-to-plan-review-1f70b32c51.md)
for [issue #80](https://github.com/JFusco/agent-review-workflows/issues/80).
New plan runs start with a separate Codex researcher, then retain independent
review, combined adjudication/refinement, and independent recheck. Research is
required without consuming either refinement attempt. Schema-2 saved runs retain
their original two-role profiles and routing, labeled research unrecorded.

The researcher defaults provisionally to Astra high. Per-field installation and
start overrides freeze into the run; researcher fallback is disabled. The brief
records local investigations, Brain committed snapshot and available activity
receipts, current primary web evidence, reuse options, alternatives, recommendation,
contradictions, unavailable sources, and assumptions. Acceptance validates identity
and source references, retains an immutable revision artifact, and binds its
digest into the target. Both review roles receive the complete accepted brief.
Comparisons preserve its provenance without manufacturing observed model settings.

A local Codex CLI check showed that its sandbox subcommand requires a named
permission profile. The researcher therefore extends `:read-only` and grants
writes only to isolated scratch and Brain's existing canonical usage-metadata
directory. Canonical artifacts, the project, and Brain knowledge stay protected.
Hosted live search remains separate from disabled command networking. Exact
contracts and recovery are maintained in the [research reference](../../references/research.md).

Verification uses synthetic research/transport/provider fixtures, temporary Git
projects, and a local sandbox file-write probe. No paid provider comparison or
production access is part of this delivery. Astra high remains provisional;
Astra high/xhigh and Opus high quality and usage comparisons remain future work.

The disposable trial creator now records a correct implementation baseline before
introducing the buggy fixture, satisfying the existing nonempty-diff start guard.
Both trial modes were created successfully without invoking a provider. The
research template is explicitly synthetic and requires the current run envelope.
The 14 focused research tests passed, including the local Codex 0.163.0 permission
probe. Source-reference uniqueness remains a helper check so the provider schema
uses the supported keyword subset.

The final `pnpm run verify:ci` passed Python/JavaScript lint, 180 Python tests,
17 tooling tests, and wiki integrity. The guarded reviewer fixture also proves
research cannot be dispatched through the reviewer-only host boundary.
