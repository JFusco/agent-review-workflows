# Evaluate review runs

Read the [comparison procedure](references/suite-eval.md). Require explicit baseline and candidate run directories. Compare their original requirements and targets exactly before drawing a comparative conclusion.

Use only recorded artifacts. Separate attempted calls from accepted stages and mark missing measurements unavailable. Judge quality only against maintainer-supplied expectations identified for this comparison.

Return the evidence and limits in the conversation. Leave both runs and reviewed projects unchanged; do not dispatch a review stage.
